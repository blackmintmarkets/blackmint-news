Solana Retires Its 'Mainnet Beta' Label After Six Years Live

Solana 1.0 is now a shared protocol version that both the Agave and Firedancer clients can point to. SOL holders don't need to do anything.

Solana is officially out of beta. The Solana Foundation on Monday retired the "mainnet beta" label the network has carried since its March 2020 launch and introduced Solana 1.0, a version number for the network's rules.

Nothing changes for SOL holders. The foundation said balances, accounts, apps and transaction history stay the same, and users don't need to swap tokens or install anything. The rename doesn't make transactions faster or cheaper on its own.

One number for two clients

A blockchain protocol is the set of rules every validator follows, and a client is the software that runs those rules. Solana now has two major clients. Agave is built by Anza. Firedancer, built separately by Jump Crypto, went live on mainnet in December 2025. Each has its own code, release schedule and version numbers.

That made it hard to say which network rules a given release supported. "A shared protocol version lets everyone refer to Solana's evolution without using one client's release number as shorthand for the entire network," the foundation wrote, as quoted by Solana Compass. Anza, the Agave team, confirmed that Agave keeps its own version numbers, Solana Compass reported.

Operators still have homework

The foundation said a protocol version "does not activate every associated improvement at once." Validator and RPC operators still need to check which client releases support each rollout and follow the activation steps in the Agave or Firedancer docs. The foundation's cluster page now lists the public endpoint as api.mainnet.solana.com, while Anza's docs still showed the mainnet-beta address on Monday, Solana Compass reported. Apps with a hard-coded "mainnet-beta" string are the ones to check against the Solana Changelog.

The rename follows Alpenglow, a consensus upgrade that went live Oct. 21 and targets finality of about 150 milliseconds, down from 12.8 seconds. Finality is the point where a transaction can't be reversed. SOL traded near $70.89 at 11:45 a.m. ET, down 0.8% in 24 hours, per CoinGecko.

In our opinion: six years and eight months is a long beta for a network that settled real money from day one, so the label was about the last thing on Solana still in testing. The useful change is the shared number, because two clients on separate version schemes need a common reference before the next upgrade. The foundation hasn't said what the next protocol version will contain or when, and that schedule is the thing to watch.
